here is the place to store the newsletters files to use in the newsletter in bento.
Files will be available in the url `https://capgo.app/newsletters/[month-year]/[filename]`.
For example, the file `09-2026/logo.png` will be available in the url `https://capgo.app/newsletters/09-2026/logo.png`.

To make the files available in the newsletter, you can use the following code:

```html
<img src="https://capgo.app/newsletters/09-2026/logo.png" alt="Logo">
```

Ensure that the file is pushed to main of the Pr is merged before sending the email.
