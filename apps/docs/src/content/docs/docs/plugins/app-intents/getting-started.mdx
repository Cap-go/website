## Install

You can use our AI-Assisted Setup to install the plugin. Add the Capgo skills to your AI tool using the following command:

```bash
npx skills add https://github.com/Cap-go/capgo-skills --skill capacitor-plugins
```

Then use the following prompt:

```text
Use the `capacitor-plugins` skill from `Cap-go/capgo-skills` to install the `@capgo/capacitor-app-intents` plugin in my project.
```

For a manual setup, install the package and sync the native projects:

```bash
npm install @capgo/capacitor-app-intents
npx cap sync
```

## Handle invocations (cold start safe)

Register a listener before you drain the pending queue so Siri, Shortcuts, Spotlight, and quick actions that fire during WebView startup are not lost.

```typescript
const handleInvocation = async (invocation) => {
  console.log(invocation.name, invocation.params, invocation.source);
};

await useAppIntentsListener(handleInvocation);
```

`useAppIntentsListener` attaches `appIntentInvoked` and then drains pending items. You can also call `getPendingInvocations()` and `removePendingInvocation()` manually if you prefer explicit control.

### Return results to Siri (tool intents)

`withInvocationCompletion`, `completeInvocation`, `failInvocation`, and `setOnscreenEntityContext` ship in plugin **8.2.0+** (see [capacitor-app-intents PR #2](https://github.com/Cap-go/capacitor-app-intents/pull/2)). npm **8.1.0** does not export them yet. Install a build from that branch or wait for the release before copying the examples below.

For typed codegen intents with `awaitJavaScriptResult: true`, wrap your handler with `withInvocationCompletion` so Siri receives a string result. The native layer uses `value` (or `summary`) for both the chained result and spoken dialog. If `value` is set, a separate `message` is not spoken. Throw on unknown awaiting intents so `withInvocationCompletion` calls `failInvocation` instead of completing with a generic `Done`:

```typescript
import { useAppIntentsListener, withInvocationCompletion } from '@capgo/capacitor-app-intents';

await useAppIntentsListener(
  withInvocationCompletion(async (invocation) => {
    if (invocation.name === 'orderDish') {
      return { value: 'Ordered pasta' };
    }
    throw new Error(`Unknown awaiting intent: ${invocation.name}`);
  }),
);
```

See [Siri app skills (iOS 27.3)](/docs/plugins/app-intents/app-skills/) for codegen, `Skills.skillsbundle`, native handlers, and device testing.

## Siri phrases (codegen)

`AppShortcut` phrases and SF Symbol names must be **compile time literals** in Swift. Configure `app-shortcuts.config.json` in your app repo and generate Swift into your iOS **App** target:

```bash
node node_modules/@capgo/capacitor-app-intents/scripts/generate-app-shortcuts.mjs \
  --config app-shortcuts.config.json \
  --output ios/App/App/CapgoGeneratedAppShortcuts.swift
```

Link the plugin SPM package to the app target so `CapgoDispatchAppIntent` resolves. On Capacitor 8, forward SceneDelegate quick actions and continued Spotlight activities with `CapgoAppIntentsLifecycle` (see the plugin repo `docs/ios-scene-integration.md`).

## API Overview

### `getPendingInvocations`

Return invocations queued before JavaScript was ready.

```typescript
import { CapgoAppIntents } from '@capgo/capacitor-app-intents';

const result = await CapgoAppIntents.getPendingInvocations();
console.log(result);
```

### `removePendingInvocation`

Remove one pending invocation after your handler processes it.

```typescript
import { CapgoAppIntents } from '@capgo/capacitor-app-intents';

await CapgoAppIntents.removePendingInvocation({ id: 'id-123' });
```

### `completeInvocation`

Resolve an invocation that is awaiting a JavaScript result for Siri.

```typescript
import { CapgoAppIntents } from '@capgo/capacitor-app-intents';

await CapgoAppIntents.completeInvocation({
  id: 'id-123',
  result: { value: 'Done' },
});
```

### `failInvocation`

Fail an invocation that is awaiting a JavaScript result.

```typescript
import { CapgoAppIntents } from '@capgo/capacitor-app-intents';

await CapgoAppIntents.failInvocation({ id: 'id-123', error: 'Could not finish.' });
```

### `setOnscreenEntityContext`

Publish optional on screen entity context for catalog queries when your UI cannot adopt native entity annotations.

```typescript
import { CapgoAppIntents } from '@capgo/capacitor-app-intents';

await CapgoAppIntents.setOnscreenEntityContext({
  entities: [{ catalogType: 'dish', entityId: 'pasta', title: 'Pasta' }],
});
```

### `clearOnscreenEntityContext`

Clear on screen entity hints when your UI no longer shows those rows.

```typescript
import { CapgoAppIntents } from '@capgo/capacitor-app-intents';

await CapgoAppIntents.clearOnscreenEntityContext();
```

### `setEntityCatalog`

Persist an entity catalog for a given type string.

Powers Siri and Shortcuts entity parameters without new Swift per row.

```typescript
import { CapgoAppIntents } from '@capgo/capacitor-app-intents';

await CapgoAppIntents.setEntityCatalog({
  type: 'type',
  entries: [
    {
      id: 'id-123',
      title: 'Hello from Capacitor',
    },
  ],
});
```

### `setHomeScreenShortcutItems`

Replace Home Screen quick actions (UIApplicationShortcutItems).

```typescript
import { CapgoAppIntents } from '@capgo/capacitor-app-intents';

await CapgoAppIntents.setHomeScreenShortcutItems({
  items: [
    {
      type: 'type',
      title: 'Hello from Capacitor',
    },
  ],
});
```

### `indexSpotlightEntities`

Index Spotlight items for your app domain.

Uses `CSSearchableItem` on iOS 16 and later. On iOS 18 and later also donates
`IndexedEntity` values through `indexAppEntities` and `associateAppEntity`.

```typescript
import { CapgoAppIntents } from '@capgo/capacitor-app-intents';

await CapgoAppIntents.indexSpotlightEntities({
  entities: [
    {
      id: 'id-123',
      title: 'Hello from Capacitor',
      actionName: 'action',
    },
  ],
});
```

### `removeSpotlightEntities`

Remove Spotlight items by id.

```typescript
import { CapgoAppIntents } from '@capgo/capacitor-app-intents';

await CapgoAppIntents.removeSpotlightEntities({ ids: ['ids'] });
```

### `performAppleSchemaTemplate`

Queue a JavaScript handler for an alpha Apple schema template.

This does not call private Mail or system schema APIs. It only enqueues an
invocation (for example `appleSchemaMailCreateDraft`) for your app code to handle.

```typescript
import { CapgoAppIntents } from '@capgo/capacitor-app-intents';

const result = await CapgoAppIntents.performAppleSchemaTemplate({
  template: 'mail_create_draft',
  params: {},
});
console.log(result);
```

## Type Reference

### `AppIntentInvocation`
A pending App Intent style invocation waiting for JavaScript.
```typescript
export interface AppIntentInvocation {
  /**
   * Stable id for this queued invocation.
   *
   * @since 0.1.0
   */
  id: string;

  /**
   * Handler name your JavaScript listens for.
   *
   * @since 0.1.0
   */
  name: string;

  /**
   * Parameters passed from Siri, Shortcuts, Spotlight, or quick actions.
   *
   * @since 0.1.0
   */
  params: Record<string, unknown>;

  /**
   * Origin of the invocation.
   *
   * @since 0.1.0
   */
  source: AppIntentInvocationSource;

  /**
   * Unix timestamp in milliseconds when the invocation was queued.
   *
   * @since 0.1.0
   */
  createdAt: number;

  /**
   * When true, the native side is waiting for `completeInvocation` or `failInvocation`.
   *
   * @since 8.2.0
   */
  awaitingResult?: boolean;
}
```
