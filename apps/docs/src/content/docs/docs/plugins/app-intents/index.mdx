## Overview

`@capgo/capacitor-app-intents` connects Apple **App Intents** to your Capacitor JavaScript layer: drain a pending queue on cold start, publish entity catalogs for Shortcuts parameters, index Spotlight content, set Home Screen quick actions, and listen for `appIntentInvoked` events. Siri shortcut **phrases** are compile time literals in generated Swift, not runtime strings.

Pair this plugin with [Siri, Shortcuts, and widgets](/docs/plugins/siri-shortcuts-widgets-and-intents/) when you also use Widget Kit, Live Activities, Share Target, or Intent Launcher.

## Siri app skills (iOS 27.3 Developer Preview)

On iOS 27.3, Apple lets apps register **app skills**: multi step instructions Siri can follow inside your app, backed by **tool intents** that return real results to Siri so actions chain in one conversation.

| Capability | What Capgo gives you |
| --- | --- |
| Multi step skills | `generate-skills-bundle.mjs` turns `SKILL.md` style entries in `app-intents.codegen.json` into `Skills.skillsbundle` for your Xcode app target. |
| Typed tool intents | `generate-typed-intents.mjs` emits Swift with parameters, entities, `foregroundOnly`, and optional `awaitJavaScriptResult`. |
| Results back to Siri | `withInvocationCompletion` and `completeInvocation()` return a string via `value` (or `summary`); that same string is spoken and chained. `message` applies only when `value` is omitted. `failInvocation()` reports an error when JavaScript cannot finish. |
| Capacitor without recompiling every action | Keep business logic in JavaScript; regenerate Swift only when intents or skill bodies change. |

**Example skill flow:** A skill body tells Siri to pick a dish from your catalog, call an `orderDish` tool intent, then speak the JavaScript order summary. The first tool returns `{ value: "pasta" }`; the second tool reads it and confirms out loud.

**Why Capgo:** One plugin covers the pending queue, entity catalogs, codegen scripts, and the bridge that lets hybrid apps return structured tool results without rewriting your web stack in Swift for every feature.

<Aside type="note">
App skills and `@AppIntent(.tool)` require iOS 27.3 SDK tooling and Apple Intelligence on a physical device for full evaluation. See the [step by step guide](/docs/plugins/app-intents/app-skills/) for guarded APIs and CI safe defaults.
</Aside>

## Platform support

| Platform | Support | Notes |
| --- | --- | --- |
| iOS | Yes | iOS 16 and later; Siri app skills and tool traits need iOS 27.3 SDK (preview) |
| Android | No | Methods reject with a clear error |
| Web | No | Guard with Capacitor.getPlatform() |

## Core Capabilities

- `getPendingInvocations` - Return invocations queued before JavaScript was ready.
- `removePendingInvocation` - Remove one pending invocation after your handler processes it.
- `setEntityCatalog` - Persist an entity catalog for a given type string.
- `setHomeScreenShortcutItems` - Replace Home Screen quick actions (UIApplicationShortcutItems).
- `completeInvocation` / `failInvocation` - Return or fail tool results when Siri awaits JavaScript (iOS 17+ chaining; skills on iOS 27.3 preview).
- `setOnscreenEntityContext` / `clearOnscreenEntityContext` - Hint visible catalog rows when the UI is web only.

## Public API

| Method | Description |
| --- | --- |
| `getPendingInvocations` | Return invocations queued before JavaScript was ready. |
| `removePendingInvocation` | Remove one pending invocation after your handler processes it. |
| `completeInvocation` | Resolve an invocation awaiting a JavaScript result for Siri. |
| `failInvocation` | Fail an invocation awaiting a JavaScript result. |
| `setOnscreenEntityContext` | Publish optional on screen entity hints for catalog queries. |
| `clearOnscreenEntityContext` | Clear on screen entity hints. |
| `setEntityCatalog` | Persist an entity catalog for a given type string. |
| `setHomeScreenShortcutItems` | Replace Home Screen quick actions (UIApplicationShortcutItems). |
| `indexSpotlightEntities` | Index Spotlight items for your app domain. |
| `removeSpotlightEntities` | Remove Spotlight items by id. |
| `performAppleSchemaTemplate` | Queue a JavaScript handler for an alpha Apple schema template. |
| `addListener` | Listen for `appIntentInvoked` when a new invocation is queued. |
| `removeAllListeners` | Remove all listeners for this plugin. |
| `getPluginVersion` | Native plugin version string. |
