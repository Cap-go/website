title: iOS setup
description: "PDFKit setup for @capgo/capacitor-pdf-viewer on iOS."
sidebar:
  order: 3
---

No extra Info.plist keys or entitlements are required. The plugin uses Apple PDFKit.

Remote PDFs download through `URLSession` with the `headers` you pass to `open`. Follow your app's App Transport Security rules for HTTPS URLs.

Password-protected PDFs are supported on iOS when you pass `password` in `open` options.
