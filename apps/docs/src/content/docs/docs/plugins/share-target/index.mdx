## Overview

`@capgo/capacitor-share-target` receives content **from** other apps (Android `SEND` / `SEND_MULTIPLE` intents and an iOS Share Extension writing into an App Group). The plugin exposes a `shareReceived` listener with title, text, and files.

On iOS, shared payloads use `notifyListeners(..., retainUntilConsumed: true)` so a share that arrives before your WebView loads is still delivered to the first listener. That is share-specific cold start handling, not a general App Intent queue.

This plugin does **not** create Siri shortcuts, Shortcuts app actions, or outgoing share targets. It is unrelated to [@capgo/capacitor-intent-launcher](/docs/plugins/intent-launcher/) (Android activities and iOS Settings).

See [Siri, Shortcuts, and widgets](/docs/plugins/siri-shortcuts-widgets-and-intents/) for a full comparison with expo-app-intents-style features.

## Core Capabilities

- `addListener` - Listen for shareReceived event.
- `removeAllListeners` - Remove all listeners for this plugin.
- `getPluginVersion` - Get the native Capacitor plugin version.
