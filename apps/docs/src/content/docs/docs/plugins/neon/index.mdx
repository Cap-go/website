## Overview

Native Neon Auth, JWT access, and basic Data API helpers for Capacitor

Start with `initialize()`; see [Getting Started](/docs/plugins/neon/getting-started/) for the core methods and examples.

## Platform support

| Platform | Support | Notes |
| --- | --- | --- |
| iOS | Yes | Native |
| Android | Yes | Native |
| Web | No | Guard with Capacitor.getPlatform() |

## Compatibility

| Plugin version | Capacitor compatibility | Maintained |
| --- | --- | --- |
| v8.\*.\* | v8.\*.\* | Yes |

The plugin major version matches Capacitor (plugin v8 for Capacitor 8). Only the latest major version is actively maintained.

## Core Capabilities

- Native [Neon Auth](https://neon.com/docs/auth/overview) client initialization.
- Email/password sign-in and sign-up.
- Email OTP, OAuth (Google, GitHub, Vercel), and session helpers.
- Native auth state listeners.
- JWT access for JavaScript or backend calls.
- Anonymous Data API tokens for signed-out users.
- Basic native `select`, `insert`, `update`, and `delete` helpers through the Neon Data API.

## Recommended Architecture

| Concern | Recommended path |
| --- | --- |
| Authentication | Use `@capgo/capacitor-neon`. |
| Session persistence and refresh | Use `@capgo/capacitor-neon`. |
| Advanced database queries | Use `@neondatabase/neon-js` with the native JWT. |
| [Neon Functions](https://neon.com/docs/compute/functions/overview) or your own API | Send the native JWT as a `Bearer` token. |
| File uploads | Use [Neon Object Storage](https://neon.com/docs/storage/overview) through a Neon Function or your API. Storage credentials stay on the server. |
| AI features | Call [Neon AI Gateway](https://neon.com/docs/ai-gateway/overview) from a Neon Function or your API. Keep the gateway token out of the app bundle. |
