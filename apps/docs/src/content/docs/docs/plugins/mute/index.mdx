## Overview

Call `isMuted()` before you fire notification sounds or haptics-only feedback. The plugin reads the iOS mute switch through AudioToolbox and Android ringer mode through `AudioManager`, with no extra permissions.

Typical fits: chat apps, games, training apps, and any UI that should show a visual cue when audio would be silent.

## Platform support

| Platform | Support | Notes |
| --- | --- | --- |
| iOS | Yes | Hardware mute switch |
| Android | Yes | Ringer mode via `AudioManager` |
| Web | No | API not available in browsers |

## Core Capabilities

- `isMuted` - Check if the device mute switch is enabled.

## Public API

| Method | Description |
| --- | --- |
| `isMuted` | Check if the device mute switch is enabled. |
| `getPluginVersion` | Get the native Capacitor plugin version. |
