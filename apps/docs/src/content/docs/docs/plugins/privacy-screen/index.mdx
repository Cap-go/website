## Overview

Enable privacy protection by default so support PINs, health data, and internal dashboards do not appear in screenshots, screen recordings, or the iOS task switcher preview. Temporarily `disable()` only for flows that must be capturable, then `enable()` again.

Android can apply secure window flags and dim overlays. iOS obscures content during app switcher snapshots. Web keeps an in memory flag for API parity only.

## Platform support

| Platform | Support | Notes |
| --- | --- | --- |
| iOS | Yes | App switcher snapshot protection |
| Android | Yes | Secure surface, screenshot and recording blocking options |
| Web | API parity | In memory enabled flag only |

## Core Capabilities

- `enable` - Enables the privacy screen.
- `disable` - Disables the privacy screen.
- `isEnabled` - Returns the current enabled state.
