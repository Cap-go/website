## Overview

Capacitor plugin for downloading files with background support. Provides resumable downloads with progress tracking.

<Aside type="tip" title="Android OkHttp engine (upcoming release)">

Opt in to **OkHttp** for downloads into app-private storage (`cache/...`, `files/...`). Use `androidHttpEngine: 'auto'` (default) or `'okhttp'`, and `notification: 'hidden'` for silent transfers with `downloadProgress` events. When `androidHttpEngine` is `'auto'`, `public-downloads/...` and other relative paths under app external files use DownloadManager. If app external files storage is unavailable, those other relative paths fall back to internal storage and `auto` selects OkHttp. `'okhttp'` rejects `public-downloads/...` paths. OkHttp transfers run in the app process and do not continue after the process is killed. This API is not in the current npm package; it ships in the next release. See [Android OkHttp engine](/docs/plugins/downloader/getting-started/#android-okhttp-engine).

</Aside>

## Completion notifications

Set `downloadCompletedNotificationText` on `download()` to show a localized system notification when a file finishes and the user granted notification permission. See [Getting Started](/docs/plugins/downloader/getting-started/#example-completion-notification) for a full example.

## Core Capabilities

- `download` - Start a new download task.
- `pause` - Pause an active download. Download can be resumed later from the same position.
- `resume` - Resume a paused download. Continues from where it was paused.
- `stop` - Stop and cancel a download permanently. Downloaded data will be deleted.
- `downloadCompletedNotificationText` (optional on `download`) - Show a localized system notification when a download succeeds and notification permission is granted.

## Public API

| Method | Description |
| --- | --- |
| `download` | Start a new download task. |
| `pause` | Pause an active download. Download can be resumed later from the same position. |
| `resume` | Resume a paused download. Continues from where it was paused. |
| `stop` | Stop and cancel a download permanently. Downloaded data will be deleted. |
| `checkStatus` | Check the current status of a download. |
| `getFileInfo` | Get information about a downloaded file. |
| `addListener` | Listen for download progress updates. Fired periodically as download progresses. |
| `addListener` | Listen for download completion. Fired when a download finishes successfully. |
| `addListener` | Listen for download failures. Fired when a download encounters an error. |
| `removeAllListeners` | Remove all event listeners. Cleanup method to prevent memory leaks. |
| `getPluginVersion` | Get the plugin version number. |
