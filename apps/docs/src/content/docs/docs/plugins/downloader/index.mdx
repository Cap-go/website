## Overview

Capacitor plugin for downloading files with background support. Provides resumable downloads with progress tracking.

<Aside type="tip" title="Android OkHttp engine (8.5.0)">

Available since **8.5.0**. When `androidHttpEngine` is omitted, behavior matches releases before 8.5.0: DownloadManager for every destination (including `cache/...` and `files/...` under app external files). Opt in to **OkHttp** for true app-private storage by setting `androidHttpEngine` to `'auto'` or `'okhttp'`, then use `cache/...` or `files/...` for internal dirs. `notification: 'hidden'` hides DownloadManager progress UI; `downloadCompletedNotificationText` can still alert on success. When `androidHttpEngine` is `'auto'`, `public-downloads/...` and other relative paths under app external files use DownloadManager. OkHttp transfers run in the app process and do not continue after the process is killed. See [Android OkHttp engine](/docs/plugins/downloader/getting-started/#android-okhttp-engine).

</Aside>

<Aside type="tip" title="Android DownloadManager notification labels (8.6.0)">

Available since **8.6.0**. Set optional `title` and `description` on `download()` to customize the Android DownloadManager progress notification. When omitted or empty, the system keeps its default (often the destination file name). **Android only** on the DownloadManager path. iOS and Web ignore both fields. The OkHttp Android path ignores them as well. See [Android DownloadManager notification labels](/docs/plugins/downloader/getting-started/#android-downloadmanager-notification-labels).

</Aside>

## Completion notifications

Set `downloadCompletedNotificationText` on `download()` to show a localized system notification when a file finishes and the user granted notification permission. See [Getting Started](/docs/plugins/downloader/getting-started/#example-completion-notification) for a full example.

## Core Capabilities

- `download` - Start a new download task.
- `pause` - Pause an active download. Download can be resumed later from the same position.
- `resume` - Resume a paused download. Continues from where it was paused.
- `stop` - Stop and cancel a download permanently. Downloaded data will be deleted.
- `downloadCompletedNotificationText` (optional on `download`) - Show a localized system notification when a download succeeds and notification permission is granted.
- `title` and `description` (optional on `download`, Android DownloadManager since 8.6.0) - Customize progress notification title and description. Ignored on iOS, Web, and OkHttp Android downloads.

## Public API

| Method | Description |
| --- | --- |
| `download` | Start a new download task. |
| `pause` | Pause an active download. Download can be resumed later from the same position. |
| `resume` | Resume a paused download. Continues from where it was paused. |
| `stop` | Stop and cancel a download permanently. Downloaded data will be deleted. |
| `checkStatus` | Check the current status of a download. |
| `getFileInfo` | Get information about a downloaded file. |
| `addListener` | Listen for download progress updates. Fired periodically as download progresses. |
| `addListener` | Listen for download completion. Fired when a download finishes successfully. |
| `addListener` | Listen for download failures. Fired when a download encounters an error. |
| `removeAllListeners` | Remove all event listeners. Cleanup method to prevent memory leaks. |
| `getPluginVersion` | Get the plugin version number. |
