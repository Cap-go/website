## Install

You can use our AI-Assisted Setup to install the plugin. Add the Capgo skills to your AI tool using the following command:

```bash
bunx skills add https://github.com/Cap-go/capgo-skills --skill capacitor-plugins
```

Then use the following prompt:

```text
Use the `capacitor-plugins` skill from `Cap-go/capgo-skills` to install the `@capgo/capacitor-rich-notifications` plugin in my project.
```

If you prefer Manual Setup, install the plugin by running the following commands and follow the platform-specific instructions below:

```bash
bun add @capgo/capacitor-rich-notifications
bunx cap sync
```

## Import

```typescript
import { RichNotifications } from '@capgo/capacitor-rich-notifications';
```

## Quick start

```typescript
import { RichNotifications } from '@capgo/capacitor-rich-notifications';

const { status } = await RichNotifications.requestPermission();
if (status !== 'granted') return;
```

## Example: createChannel

```typescript
import { RichNotifications } from '@capgo/capacitor-rich-notifications';

await RichNotifications.createChannel({
  id: 'alerts',
  name: 'Alerts',
  importance: 'high',
});
```

## Example: display

```typescript
import { RichNotifications } from '@capgo/capacitor-rich-notifications';

const { id } = await RichNotifications.display({
  title: 'Hello',
  body: 'Tap to open',
  channelId: 'alerts',
});
```

## Common pitfalls

- **Listeners**: remove handles when screens unmount.
- **Native sync**: run `bunx cap sync` after plugin upgrades.
- **Source of truth**: trust `src/definitions.ts` in the GitHub repo.

## Platform setup

- [iOS setup](/docs/plugins/rich-notifications/ios/) for categories and interruption levels.
- [Android setup](/docs/plugins/rich-notifications/android/) for `POST_NOTIFICATIONS`, channels, and optional exact alarm or foreground service permissions.

## Usage

```typescript
import { RichNotifications } from '@capgo/capacitor-rich-notifications';

await RichNotifications.requestPermission();

await RichNotifications.createChannel({
  id: 'messages',
  name: 'Messages',
  importance: 'high',
});

await RichNotifications.display({
  title: 'Hello',
  body: 'Tap to open the app',
  channelId: 'messages',
});

await RichNotifications.addListener('press', (event) => {
  console.log(event.id, event.actionId, event.input);
});
```
