## Overview

`@capgo/capacitor-media-session` wires your Capacitor player into the OS **now playing** surface: lock screen, notification controls, headsets, and CarPlay style remotes. Set title and artwork, publish playback state, and react to play, pause, seek, and skip actions from native UI.

Use it for podcasts, music, audiobooks, and long form video where users expect hardware button control.

## Platform support

| Platform | Implementation |
| --- | --- |
| iOS | Web implementation adapter (`navigator.mediaSession`; rejects when unavailable) |
| Android | Media session service |
| Web | Media Session API |

## Core Capabilities

- `setMetadata` - Sets metadata of the currently playing media.
- `setPlaybackState` - Updates the playback state of the media session.
- `setActionHandler` - Registers a handler for a media session action.
- `setPositionState` - Updates position state for the active media session.
