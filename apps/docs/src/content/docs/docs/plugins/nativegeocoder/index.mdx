## Overview

Convert GPS coordinates into postal addresses for display, or turn user typed addresses into map pins. Cap results with `maxResults`, honor locale preferences on native platforms, and supply a Google API key for web forward and reverse lookups.

Typical fits: delivery apps, store locators, check in flows, and autocomplete backends that need structured address components.

## Platform support

| Platform | Support | Notes |
| --- | --- | --- |
| iOS | Yes | Core Location geocoder |
| Android | Yes | Android `Geocoder` |
| Web | Yes | Google Geocoding API with `apiKey` |

## Core Capabilities

- `reverseGeocode` - Convert latitude and longitude to an address.
- `forwardGeocode` - Convert an address to latitude and longitude.

## Public API

| Method | Description |
| --- | --- |
| `reverseGeocode` | Convert latitude and longitude to an address. |
| `forwardGeocode` | Convert an address to latitude and longitude. |
| `getPluginVersion` | Get the native Capacitor plugin version. |
