## Overview

`@capgo/capacitor-twilio-video` wraps the Twilio Video native SDKs for Capacitor apps. Your backend still mints access tokens. The plugin handles permissions, room lifecycle, media toggles, and a native call UI on top of the WebView. Install it with the [Capgo skills](https://capgo.app/skills/?ref=plugin_twilio_video) or follow the [getting started guide](/docs/plugins/twilio-video/getting-started/).

## Native SDK floors

| Platform | SDK | Floor in this plugin |
| --- | --- | --- |
| iOS | [twilio-video-ios](https://github.com/twilio/twilio-video-ios) | Swift Package Manager `from: "5.11.3"`. CocoaPods `TwilioVideo ~> 5.11` allows any 5.11.x and does not by itself require 5.11.3. |
| Android | `com.twilio:video-android` | 7.10.5 |

## Platform support

| Platform | Support | Notes |
| --- | --- | --- |
| iOS | Yes | iOS 15+, native overlay, Twilio Video iOS 5.11.3+ |
| Android | Yes | API 24+, native overlay, Twilio Video Android 7.10.5 |
| Web | No | All methods throw `unimplemented` |

## Core capabilities

- `login` stores and validates a Twilio Video access token minted by your backend.
- `joinRoom` connects to a room with optional audio and video tracks and shows the native call surface. Defaults: `enableAudio: true`, `enableVideo: false`.
- `setMicrophoneEnabled` and `setCameraEnabled` publish or unpublish local tracks while connected.
- Listener events cover room connect, disconnect, reconnect, and remote participant changes.
- Permission helpers cover microphone and camera on both native platforms.

## Public API

| Method | Description |
| --- | --- |
| `login` | Store and validate a Twilio Video access token minted by your backend. |
| `logout` | Clear the cached access token and leave the active room. |
| `isLoggedIn` | Check whether a valid Twilio token is currently cached on the device. |
| `joinRoom` | Join a Twilio room and present the plugin's native in-app call overlay. |
| `leaveRoom` | Leave the current room if connected. |
| `setMicrophoneEnabled` | Enable or disable local microphone publishing. |
| `setCameraEnabled` | Enable or disable local camera publishing. |
| `getCallStatus` | Return room name, media state, and participant count. |
| `checkMicrophonePermission` | Check microphone permission state. |
| `requestMicrophonePermission` | Request microphone permission. |
| `checkCameraPermission` | Check camera permission state. |
| `requestCameraPermission` | Request camera permission. |
| `addListener` | Listen for room connected events. |
| `addListener` | Listen for room disconnected events. |
| `addListener` | Listen for participant connected events. |
| `addListener` | Listen for participant disconnected events. |
| `addListener` | Listen for reconnection start events. |
| `addListener` | Listen for reconnection success events. |
| `removeAllListeners` | Remove every listener registered through this plugin instance. |
