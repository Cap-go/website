## Overview

Enable native proximity monitoring so your app can react when the device is near a face, hand, or surface

Start with `enable()` and the other core methods listed below.

## Platform support

| Platform | Support | Notes |
| --- | --- | --- |
| iOS | Yes | Native |
| Android | Yes | Native |
| Web | Partial | See getting started |

## Core Capabilities

- `enable` - Enable proximity monitoring.
- `disable` - Disable proximity monitoring.
- `getStatus` - Get the current sensor availability and plugin enabled state.

## Public API

| Method | Description |
| --- | --- |
| `enable` | Enable proximity monitoring. |
| `disable` | Disable proximity monitoring. |
| `getStatus` | Get the current sensor availability and plugin enabled state. |
| `getPluginVersion` | Get the current native plugin version. |
