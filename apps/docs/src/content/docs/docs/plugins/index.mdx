## Capgo Cloud - Live Updates

<LinkCard
  title="Capacitor Updater"
  description="The core plugin powering Capgo Cloud. Deliver instant updates to your Capacitor apps without waiting for app store review."
  href="/docs/plugins/updater/"
/>

The Updater plugin is the foundation of Capgo Cloud and lets you:

- Deploy JavaScript, HTML, CSS, and asset changes in minutes.
- Roll out updates to targeted user groups with channels.
- Monitor adoption and failure signals from the Capgo console.
- Secure releases with encryption and code signing.
