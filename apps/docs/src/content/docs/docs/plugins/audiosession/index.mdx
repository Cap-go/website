## Overview

Read active outputs and override speaker routes before other audio plugins fight over AVAudioSession.

## Platform support

| Platform | Support | Notes |
| --- | --- | --- |
| iOS | Yes | AVAudioSession routing |
| Android | No | No audio routing; `currentOutputs()` and `overrideOutput()` are iOS-only |
| Web | No | Browser policies differ |

## Core Capabilities

- `currentOutputs` - Get the current active audio output routes.
- `overrideOutput` - Override the current audio output route.

## Public API

| Method | Description |
| --- | --- |
| `currentOutputs` | Get the current active audio output routes. |
| `overrideOutput` | Override the current audio output route. |
| `addListener` | Listen for audio route changes (e.g. headset connected/disconnected). |
| `addListener` | Listen for audio session interruptions (e.g. incoming call) and their end. |
| `getPluginVersion` | Get the native Capacitor plugin version. |
