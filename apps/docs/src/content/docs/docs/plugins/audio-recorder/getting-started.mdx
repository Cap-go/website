```bash
npx skills add https://github.com/Cap-go/capgo-skills --skill capacitor-plugins
```

Then use the following prompt:

Use the `capacitor-plugins` skill from `Cap-go/capgo-skills` to install the `@capgo/capacitor-audio-recorder` plugin in my project.

## Quick start

Request the microphone, record, then stop and read the native file URI (or web `Blob`).

```typescript
import { Capacitor } from '@capacitor/core';
import { CapacitorAudioRecorder } from '@capgo/capacitor-audio-recorder';

const mic = await CapacitorAudioRecorder.requestPermissions();
if (mic.recordAudio !== 'granted') {
  throw new Error('Microphone permission required');
}

await CapacitorAudioRecorder.startRecording({
  sampleRate: 44100,
  bitRate: 128000,
  resetToPlaybackOnStop: true, // iOS only: restore playback-friendly audio session after stop
});

const { uri, blob, duration } = await CapacitorAudioRecorder.stopRecording();
const clipRef = Capacitor.getPlatform() === 'web' ? blob : uri;
console.log('Saved clip', clipRef, duration);
```

## Crash-safe recording (`format: 'aac'`)

Requires `@capgo/capacitor-audio-recorder` **8.4.0** or newer from [capacitor-audio-recorder PR #35](https://github.com/Cap-go/capacitor-audio-recorder/pull/35/). Merge and release that plugin change before relying on this API in production.

### When to use it

Use `format: 'aac'` for irreplaceable audio: interviews, compliance notes, medical or legal memos, and any clip where losing the whole file is worse than losing the tail after an abnormal end.

Keep the default `format: 'm4a'` when you control the lifecycle (short clips, always in foreground, you can tolerate losing a take on crash) or when downstream tools expect `.m4a` and never `.aac`.

### How it works

| `format` | Container | After an abnormal end (crash, kill, dead battery) |
| --- | --- | --- |
| `'m4a'` (default) | MPEG-4 AAC in `.m4a` | Often **unreadable** until `moov` is written at `stop()` |
| `'aac'` | ADTS AAC in `.aac` | **Readable** up to the last complete frame |

Encoding settings are the same AAC bit rate and sample rate you already pass to `startRecording`. Web ignores `format` and keeps using the browser `MediaRecorder`.

```typescript
await CapacitorAudioRecorder.startRecording({
  format: 'aac',
  sampleRate: 44100,
  bitRate: 128000,
});
```

### Tradeoffs

- **Playback and sharing**: `.aac` (ADTS) is widely supported on mobile but some desktop pipelines expect `.m4a`. Convert in your backend if reviewers require MPEG-4.
- **File size and seeking**: ADTS has no index like MPEG-4. Seeking and duration metadata can be less precise until the file is fully finalized.
- **iOS interruptions**: Phone calls and audio session handoffs can leave multiple segment files. On stop, the plugin joins ADTS segments without re-encoding when possible.

### Platform notes for `stopRecording`

**Android**

- When `MediaRecorder.stop()` throws, `stopRecording` **rejects** but the file stays on disk. Read `error.data.uri` and `error.data.duration` (milliseconds) from the Capacitor rejection to keep the partial clip.
- File names are `recording-yyyyMMdd-HHmmss-<uuid>.m4a` or `.aac`, matching `format`. The UUID keeps two recordings started in the same second from overwriting each other. Earlier versions used `recording-yyyyMMdd-HHmmss.m4a` (no UUID, always `.m4a`).

```typescript
import type { StopRecordingResult } from '@capgo/capacitor-audio-recorder';

try {
  const clip = await CapacitorAudioRecorder.stopRecording();
  await upload(clip.uri!, clip.duration);
} catch (error: unknown) {
  const data = (error as { data?: Pick<StopRecordingResult, 'uri' | 'duration'> }).data;
  if (data?.uri) {
    await upload(data.uri, data.duration);
  } else {
    throw error;
  }
}
```

**iOS**

- Interrupted `'aac'` recordings are merged into one `.aac` when joining succeeds.
- When joining fails (for example disk full), `stopRecording` can **resolve** with `mergeFailed: true`, a fallback `uri`, and `segments: string[]` listing every segment in order. For `'aac'`, do not blindly concatenate raw files: a segment can end with an incomplete ADTS frame, and naive concatenation can break playback of what follows. Copy only complete frames from each segment (the plugin's join logic does this), or upload each segment separately and stitch server-side. For `'m4a'`, segments cannot be joined by concatenation; remux them or stitch them server-side.
- When finalization fails with no usable fallback segment, `stopRecording` **rejects** but segment files remain on disk.

```typescript
const result = await CapacitorAudioRecorder.stopRecording();
if (result.mergeFailed && result.segments?.length) {
  console.warn('Join failed, segments on disk', result.segments, result.uri);
}
```

`startRecording` now rejects when `AVAudioRecorder.record()` returns `false` (for example the mic is in use elsewhere) instead of returning an empty take.

## Example: voice memo with pause

```typescript
await CapacitorAudioRecorder.startRecording();
// user taps pause during a long note
await CapacitorAudioRecorder.pauseRecording();
await CapacitorAudioRecorder.resumeRecording();
const clip = await CapacitorAudioRecorder.stopRecording();
```

`pauseRecording` is available on Android (API 24+), iOS, and Web.

## Example: live level meter

Poll `getCurrentAmplitude()` on a timer (about 60 to 100 ms) while status is `RECORDING`. Values are normalized `0` to `1`, but the underlying signal differs by platform (peak on Android, average power on iOS, RMS on Web). Apply a small per platform scale if you need visual parity.

```typescript
const tick = async () => {
  const { status } = await CapacitorAudioRecorder.getRecordingStatus();
  if (status !== 'RECORDING') return;
  const { value } = await CapacitorAudioRecorder.getCurrentAmplitude();
  updateMeterUi(value);
};
```

## Example: discard a take

```typescript
await CapacitorAudioRecorder.startRecording();
await CapacitorAudioRecorder.cancelRecording(); // no file persisted
```

## Common pitfalls

- **Web vs native return shape**: Android and iOS return `uri` from `stopRecording`. Web returns `blob` (and may omit `uri`).
- **Crash safety vs default format**: only `format: 'aac'` on Android and iOS keeps audio playable after a hard stop. Default `.m4a` needs a clean `stopRecording` to stay readable.
- **Failed stop on Android**: handle `stopRecording` rejections and read `error.data` for `uri` and `duration` instead of assuming the file was deleted.
- **Android file names**: do not parse the old `recording-yyyyMMdd-HHmmss.m4a` pattern. Current files include a UUID and may end in `.aac` when you opt into `format: 'aac'`.
- **iOS merge failures**: when `mergeFailed` is true, use `segments` or the fallback `uri` from the resolved result.
- **Quiet playback on iOS after recording**: set `resetToPlaybackOnStop: true` in `startRecording` if users play back the clip inside the same session.
- **Background capture**: the plugin does not enable background audio by itself. On iOS, add the Audio background mode when you need recording while locked.
- **Do not spam amplitude**: each `getCurrentAmplitude` call crosses the bridge. Use a UI interval, not a tight loop.

## API Overview

### `startRecording`

Start recording audio using the device microphone.

```typescript
import { CapacitorAudioRecorder } from '@capgo/capacitor-audio-recorder';

await CapacitorAudioRecorder.startRecording();
```

### `pauseRecording`

Pause the ongoing recording. Only available on Android (API 24+), iOS, and Web.

```typescript
import { CapacitorAudioRecorder } from '@capgo/capacitor-audio-recorder';

await CapacitorAudioRecorder.pauseRecording();
```

### `resumeRecording`

Resume a previously paused recording.

```typescript
import { CapacitorAudioRecorder } from '@capgo/capacitor-audio-recorder';

await CapacitorAudioRecorder.resumeRecording();
```

### `stopRecording`

Stop the current recording and persist the recorded audio.

On Android, when the recorder cannot stop cleanly, the call is rejected and the recording file is kept on disk. The rejection's `data.uri` points to it and `data.duration` reports elapsed time.

On iOS, when the segments of an interrupted `'aac'` recording cannot be joined but a fallback segment exists, the call resolves with `mergeFailed` and `segments`. When finalization fails with no fallback segment, the call is rejected and segment files remain on disk.

```typescript
import { CapacitorAudioRecorder } from '@capgo/capacitor-audio-recorder';

const result = await CapacitorAudioRecorder.stopRecording();
console.log(result);
```

### `cancelRecording`

Cancel the current recording and discard any captured audio.

```typescript
import { CapacitorAudioRecorder } from '@capgo/capacitor-audio-recorder';

await CapacitorAudioRecorder.cancelRecording();
```

### `getRecordingStatus`

Retrieve the current recording status.

```typescript
import { CapacitorAudioRecorder } from '@capgo/capacitor-audio-recorder';

const result = await CapacitorAudioRecorder.getRecordingStatus();
console.log(result);
```

### `getCurrentAmplitude`

Retrieve the current input amplitude (microphone level) as a normalized
number in the `[0, 1]` range.

Intended for driving live visualizations such as VU meters or waveforms
while recording. Returns `0` when no recording is active. Designed for
UI-rate polling. A 60 to 100 ms interval is a good starting point for a
waveform. Avoid calling it in a tight loop; each call crosses the
JS/native bridge.

```typescript
import { CapacitorAudioRecorder } from '@capgo/capacitor-audio-recorder';

const result = await CapacitorAudioRecorder.getCurrentAmplitude();
console.log(result);
```

### `checkPermissions`

Return the current permission state for accessing the microphone.

```typescript
import { CapacitorAudioRecorder } from '@capgo/capacitor-audio-recorder';

const result = await CapacitorAudioRecorder.checkPermissions();
console.log(result);
```

### `requestPermissions`

Request permission to access the microphone.

```typescript
import { CapacitorAudioRecorder } from '@capgo/capacitor-audio-recorder';

const result = await CapacitorAudioRecorder.requestPermissions();
console.log(result);
```

export interface GetCurrentAmplitudeResult {
  /**
   * The current input amplitude normalized to the `[0, 1]` range, where `0`
   * represents silence and `1` represents the maximum level the platform can
   * report. The value is `0` when no recording is active.

   * per-platform scaling curve.

   * @since 8.1.0

}
