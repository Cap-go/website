## What is this about?

EU and global customers often need VAT numbers and a billing address on invoices without using Stripe Customer Portal. The console billing profile shipped on Capgo main in [PR #4148](https://github.com/Cap-go/capgo/pull/4148/) and [PR #4160](https://github.com/Cap-go/capgo/pull/4160/). Organization **Super Admin** and **Billing Manager** roles can edit those fields on the Billing tab.

## Where to find it

Go to [Organization settings](/docs/webapp/settings/#how-to-get-to-the-settings-page), select the **Organization** tab, open the **Billing** tab, then scroll to the billing profile section (invoice details and tax IDs).

## Invoice details

Open **Edit details** to change:

- Organization or buyer name (required)
- Billing email (required)
- Phone (optional)
- Address line 1 (required)
- Address line 2 (optional)
- City, state or province, postal code
- Country (required, pick from the country dropdown)

Save applies all fields in the modal. The country you pick must be in the supported country list (`BILLING_COUNTRIES`).

## Tax IDs

The summary lists every stored tax ID with its type label, value, and verification status (`pending`, `unavailable`, `unverified`, or `verified`).

Open **Manage tax IDs** to add or remove entries:

- **Remove:** click **Remove** on one ID, confirm, then Capgo deletes that ID from Stripe.
- **Add:** choose **Tax ID type** from the dropdown (options come from the static `BILLING_TAX_ID_TYPES` list, for example `eu_vat`), enter the value, then click **Add**.

You can keep multiple tax IDs. The type dropdown is not locked after you add an ID; removal always uses the Remove and confirm flow, not an empty save.

## Who can edit

The UI checks `org.update_billing`. Only organization **Super Admin** and **Billing Manager** pass that check and see edit actions. **Admin**, **Member**, and other roles can still open Billing for read-only views but cannot save invoice details or change tax IDs.
