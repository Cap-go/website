# Ad copy: AI app builder to mobile

One section per landing page. Each ad names one builder, and the page repeats that name on the first screen.

## Message match rules

- Page H1: "Turn your {Builder} app into iOS and Android apps". Every ad's primary text opens with this sentence, word for word.
- Badge above the H1: "For {Builder} builders: no Mac, no Xcode". Reuse "No Mac, no Xcode" as is.
- The page button says **"Get started for free"**, with "14-day unlimited free trial. No credit card required." underneath. Use "Sign up" or "Learn more" as the platform CTA. Don't promise anything the page doesn't say (no "free forever", no "1 click").
- Hero stats you can reuse: "No Mac", "2–3 min typical native build", "Live updates".
- Judge each builder on `registration_completed`. Run one builder at a time on a small budget.

Character limits: Meta headline ≤ 40, Google RSA headline ≤ 30, Google description ≤ 90. Counts are in brackets.
